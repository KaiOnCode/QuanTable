# 新闻分析技能

## 输入
- 股票代码
- 新闻窗口天数（默认 7 天）
- 当前持仓比例

## 工作流程
1. 通过 `get_news` 获取近期新闻
2. 识别关键事件和叙事主题
3. 评估正面/负面/中性情绪分布
4. 判断事件对股价的潜在影响方向和幅度

## 输出格式
- 方向: [看涨/看跌/震荡]
- 时间范围: [日内/1-3天/1-4周/长期]
- 置信度: [0.0-1.0]
- 一句话结论: [核心判断]

## 分析框架
1. **事件识别**: 按重要性排序的关键新闻事件；区分一次性事件和持续性趋势
2. **情绪评估**: 正面/负面/中性新闻比例；标题情绪vs内容情绪的差异
3. **影响量化**: 估计对股价的影响方向；合理的涨跌幅预期区间
4. **时效性**: 新闻新鲜度；市场反应程度（是否已price in）
5. **风险因素**: 后续事件风险；情绪反转可能

## 注意事项
- 只使用输入事实；未知项以 "Unknown: ..." 标注并说明影响
- 区分客观事实和主观解读
- 注意新闻来源的可靠性差异
